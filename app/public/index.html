    Security model

    Deliberately private

    Stored values leave Keychain only when you explicitly reveal or copy a key.

    • Loopback onlyThe interface accepts connections from this Mac.
    • Values stay maskedA value appears only when you reveal it; copying sends it to the shared system clipboard.
    • Fresh confirmationEvery reveal, copy, rename, replace, and delete is authenticated by macOS.
    • No request logsSecret values are not logged. Clear the system clipboard after pasting sensitive values.

    The first edit may also trigger a Keychain access prompt for the new vault editor.
